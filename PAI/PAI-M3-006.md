# Zadanie PAI-M3-006: Dopasuj funkcję

Dana jest tablica:

```php
$p = ["Kasia" => 7, "Tomek" => 3, "Ola" => 9, "Bartek" => 5];
```

Do każdego wyniku dopasuj funkcję sortującą: `sort`, `rsort`, `asort`, `arsort`, `ksort`, `krsort`.

| |Wynik po sortowaniu|Funkcja|
|---|---|---|
|A|`[0 => 3, 1 => 5, 2 => 7, 3 => 9]`||
|B|`["Ola" => 9, "Kasia" => 7, "Bartek" => 5, "Tomek" => 3]`||
|C|`["Bartek" => 5, "Kasia" => 7, "Ola" => 9, "Tomek" => 3]`||
|D|`["Tomek" => 3, "Bartek" => 5, "Kasia" => 7, "Ola" => 9]`||
|E|`["Tomek" => 3, "Ola" => 9, "Kasia" => 7, "Bartek" => 5]`||
|F|`[0 => 9, 1 => 7, 2 => 5, 3 => 3]`||

Który wynik jest najlepszy do pokazania rankingu uczniów? Dlaczego wyniki A i F są bezużyteczne do rankingu?
